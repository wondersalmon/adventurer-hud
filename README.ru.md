# Adventurer HUD

[English version](README.md)

[![Foundry VTT 14](https://img.shields.io/badge/Foundry_VTT-14-2f855a?style=flat-square)](https://foundryvtt.com/)
[![D&D 5e 5.3+](https://img.shields.io/badge/D%26D_5e-5.3%2B-2f855a?style=flat-square)](https://github.com/foundryvtt/dnd5e)

Интерфейс персонажа и боя для игроков в Foundry VTT 14 с системой D&D 5e.

![Adventurer HUD](docs/media/image.png)

## Установка

В Foundry VTT откройте **Установить модуль**, вставьте ссылку на манифест и
нажмите **Установить**:

```text
https://github.com/wondersalmon/adventurer-hud/releases/latest/download/module.json
```

## Совместимость

- Foundry VTT 14
- D&D 5e 5.3 или новее; проверенная версия в манифесте — 6.0.3
- Не требует других модулей

HUD использует броски Foundry и D&D 5e. Другие модули могут менять поведение
бросков; для работы Adventurer HUD модуль автоматизации не нужен.

## Возможности

- Режим исследования и боевой режим с кнопкой спасброска от смерти при 0 ОЗ
- Проверки, спасброски, навыки, инструменты, заклинания, оружие и действия
- ОЗ, временные ОЗ, КД, скорость, инициатива, ресурсы, состояния и ячейки заклинаний
- Нативное использование предметов и модификаторы бросков
- Поиск предметов, выбор активности в HUD и избранное для персонажа
- Автоматическое переключение между исследованием и боем
- Адаптивная компоновка, размер текста, отключаемые анимации и сохранение положения окна
- Настраиваемая клавиша (`Shift+R` по умолчанию) и необязательная кнопка в панели токенов

## Использование

Нажмите `Shift+R`, чтобы открыть HUD выбранного токена. Если токен не выбран,
откроется назначенный вам персонаж. Кнопку в панели токенов можно включить в
дополнительных настройках. Боевой режим включается, когда персонаж участвует
в начатом бою. Модуль не добавляет участников боя.

Карточки предметов используют процесс D&D 5e. Кнопка с книгой открывает лист
предмета. Поиск находит названия предметов и активностей среди боевых действий,
заклинаний и инвентаря. Звезда сохраняет предмет или активность в избранном для
этого персонажа. Если у предмета несколько активностей, нажатие открывает их
выбор; Shift-нажатие запускает нативное использование предмета.

Кнопки бросков поддерживают нативные модификаторы: `Shift` выполняет быстрый
обычный бросок, `Alt` запрашивает преимущество, а `Ctrl` — помеху. Точное
поведение может зависеть от настроек D&D 5e и модулей автоматизации.

Нажмите на полоску ОЗ, чтобы изменить обычные и временные ОЗ. Введите `12`,
чтобы задать значение, `+5`, чтобы прибавить, или `-3`, чтобы сначала снять
временные ОЗ, а затем обычные. Поле временных ОЗ меняет их напрямую. Пустое
поле оставит значение без изменений. Полоса ОЗ видна в мирном и боевом режимах.

При 0 ОЗ HUD становится серым, персонаж помечается как «Без сознания», а под
полосой ОЗ появляется красная кнопка спасброска от смерти в любом из двух режимов.
Счётчиков успехов и провалов нет; после трёх провалов появляется сообщение
о смерти. Результаты бросков обрабатывает D&D 5e.

В разделе навыков по умолчанию показаны навыки с владением и экспертизой.
Переключатель «Все навыки» откроет полный список; выбор сохраняется для пользователя.

HUD также можно открыть из макроса:

```js
game.modules.get("adventurer-hud").api.open();
```

## Настройка

Откройте настройки модуля в Foundry или через меню заголовка HUD. В основных
настройках находятся язык, размер текста, закрытие после броска, отслеживание
выбранного токена и ручное переключение режимов. **Дополнительные настройки**
объединяют поиск и избранное, использование предметов, отображение HUD и
управление.

Отключите **Визуальные эффекты HUD**, чтобы убрать вспышки при уроне и лечении,
анимацию ОЗ и подсветку инициативы. Цвета ОЗ и подписи состояний сохранятся.
Настройка кнопки в панели токенов применяется после обновления страницы Foundry.
В меню заголовка HUD также можно закрепить окно, включить закрытие после броска
и сбросить размер и положение окна.

Настройки и избранное сохраняются для пользователя, размер и положение окна —
для клиента. Избранное HUD не меняет избранное в листе персонажа D&D 5e.

## Разработка

Требуется Node.js 22 или новее.

```text
npm ci
npm run check
npm run build
```

Контракт системного адаптера и шаги по добавлению игровой системы описаны в
[руководстве по адаптерам](docs/system-adapters.md). Код HUD находится в
`scripts/hud`, код D&D 5e — в `scripts/dnd5e`, стили — в `styles`.
