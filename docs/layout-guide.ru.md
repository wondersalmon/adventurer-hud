# Редактор компоновки HUD

[Гайд игрока](player-guide.ru.md) · [Гайд мастера](gm-guide.ru.md) · [English](layout-guide.md)

Нажмите перо рядом с булавкой, чтобы включить **Редактирование HUD**. Во время редактирования карточки меняют компоновку вместо использования способностей.

## Расположение элементов

- **Перемещение:** перетаскивайте блок за ручку или меняйте положение стрелками. Кнопки начала и конца перемещают его к соответствующему краю списка.
- **Колонки:** стрелки влево и вправо переносят блоки между колонками. При необходимости добавьте дополнительную колонку через панель редактора.
- **Ширина:** снимите фиксацию окна и перетаскивайте разделители колонок. В узком окне содержимое располагается друг под другом.
- **Карточки и категории:** меняйте их порядок собственными кнопками.

Вес и деньги остаются единым блоком внутри инвентаря. Его можно скрыть или показать, но нельзя перемещать.

## Скрытие, возврат и отмена

Нажмите глаз, чтобы скрыть элемент. Верните его через **Скрытые элементы** или кнопки скрытых карточек и категорий в соответствующем списке.

**Отмена** возвращает последнее изменение в текущем сеансе редактирования. **Сброс компоновки** восстанавливает исходное расположение текущего режима. Выйдите из редактирования, чтобы пользоваться панелью; компоновка сохранится.

## Общие компоновки

По умолчанию компоновки блоков игрока общие для персонажей, отдельно для исследования и боя. Включите **Отдельную компоновку для каждого персонажа**, если нужны индивидуальные варианты.

Компоновки мастера общие для существ, отдельно для подготовки и боя. Редактирование HUD не меняет порядок предметов и избранное в листе персонажа.
