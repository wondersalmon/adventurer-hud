# GM HUD

[Module README](../README.md) · [Player guide](README.player.md) · [Русская версия](README.gm.ru.md)

A combat panel for Foundry VTT 14 and D&D 5e 5.3+. GMs open this mode by default; players keep their character HUD.

## Open the panel

Open the HUD with **Shift+R** or its dragon button in Token Controls, if enabled.

## Layout and settings

Resize between a narrow vertical panel and a wide, low layout. The bottom turn controls stay visible.

Assign **GM: Previous turn**, **GM: Next turn** and **GM: End turn** in Foundry's **Configure Controls**. They work while the GM HUD is open.
